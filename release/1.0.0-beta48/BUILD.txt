OPPower 1.0.0-beta48 构建说明
================================

修顶栏：滚动时大标题和正文一起滚走，不再把标题钉在顶部。

问题
----
ColorOS 设置页滚动时，整块顶栏（含「设置」两个大字）一起移出屏幕，
滚回顶部时再滑下来。

OPPower 用的是 COUI 的 `LargeTopAppBar` + `exitUntilCollapsedScrollBehavior`，
这是 Material 的语义：标题一路缩成 52dp 的紧凑顶栏并**一直钉在顶部**，
滚多远都在。两者观感差得很明显。

这里有个约束：COUI 只提供 `exitUntilCollapsedScrollBehavior` 一个工厂，
没有 `enterAlways`/`pinned` 变体；`CouiCollapsingAppBarState` 是
`internal constructor`，`offsetPx` 也是 `internal`。所以在应用侧既不能构造
自己的状态，也不能写偏移。

绕法
----
读 `TopAppBar.kt` 的 layout 段发现：

    val expanded = expandedHeight.roundToPx()
    val collapsed = collapsedHeight.roundToPx()
    val range = (expanded - collapsed).coerceAtLeast(0)
    val offset = (state?.offsetPx ?: 0f).coerceIn(0f, range.toFloat())
    val height = constraints.constrainHeight((expanded - offset).roundToInt())

顶栏高度 = expanded - offset。**把 expandedHeight 和 collapsedHeight 传成同一个值，
range 就是 0，COUI 那套折叠逻辑自动失效**，高度完全由 offset 决定。于是：

1. `LargeTopAppBar(expandedHeight = H, collapsedHeight = H)`，不传 scrollBehavior，
   不挂 nestedScroll —— 它不会自己去收标题；
2. `Modifier.graphicsLayer { translationY = -offset; alpha = 1 - ratio }` 把整块顶栏
   上移到屏幕外；
3. 正文的顶留白**反向**减去同样的 offset。

第 3 步是这块唯一的坑。Scaffold 给的顶留白里已经含了顶栏的高度：

    // 只上移顶栏、不收回留白 → 正文原地不动，顶栏在它上方，中间空出一条缝
    // 照搬 COUI 的 contentPadding（顶栏收多少、正文让出多少）→ 上移和让白
    //   互相抵消，正文一动不动
    // 正确做法：base - offset，且不取负

符号搞反了，真机上表现为"标题能缩但正文不动"，很难一眼看出原因。
`PinnedLargeTopAppBarTest` 用数值把这条钉住了。

退让范围取「顶栏 110dp + 状态栏高度」。不加上状态栏那一段，退到底时标题已经
滚走、但顶栏容器还留着一条状态栏高的空白，正文顶部会空一块。

装完要看的地方
--------------
1. 设置 → 任意二级页（如「外观设置」）：向上滑，顶栏和标题应该**一起**滑走，
   不应留下一条 52dp 的顶栏。
2. 滑回顶部：标题应该跟着滑回来，不应残留半透明。
3. 滑到底：正文顶部不应空出一块（这是"留白没反向减"的症状）。
4. 状态栏区域：滑到底时状态栏文字仍可读，不应有顶栏残余色块压在上面。

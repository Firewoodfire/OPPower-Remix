这一版做了什么
--------------
上一版（beta34）仍然是自己照着 COUI 的度量重写了一遍组件，只是把结构改成了
"组 + 行"。这一版把 ui/coui/ 下 5 个文件、约 1000 行仿制实现**整体删除**，
改为直接依赖 Maven Central 上已发布的库：

    implementation("io.github.itoseo:coui:$couiVersion")        // 0.0.1-alpha16
    implementation("io.github.itoseo:coui-icons:$couiVersion")

界面全部走库的公开 API：
  layout.Group / Item / Divider / Footer / Scaffold
  text.Text + rememberCouiTextStyle(CouiTextKind.xxx)
  switch.Switch / CouiSwitchDefaults
  slider.Slider
  segmentbutton.SegmentedControl
  dialog.Dialog / CouiDialogAction
  topappbar.TopAppBar / TopAppBarButton
  shape.CouiShape / CouiCapsuleShape
  theme.CouiTheme + CouiColorScheme

ui/CouiKit.kt 保留，但只剩参数预设（与 COUI 官方 demo 的 DemoPreferenceRows.kt
同一做法）：CouiRow = Item + 两个 Text + Next 图标；CouiSwitchRow = Item + Switch；
CouiPage = Scaffold + TopAppBar + couiVerticalScroll。项目里不再有第二套度量。

工具链迁移（不迁移就消费不了这个 AAR）
--------------------------------------
Gradle        8.13     -> 9.6.0   （wrapper 指向腾讯云镜像；官方源 307 后不可达）
AGP           8.10.1   -> 9.4.1
Kotlin        2.1.21   -> 2.4.20  （Compose 编译器插件）
SDK           36       -> 37.2
minSdk        26       -> 34
AGP 9 内置 Kotlin 支持，因此 org.jetbrains.kotlin.android 插件必须移除，
否则报 "no longer required for Kotlin support since AGP 9.0"。

遇到的坑
--------
1. minSdk 必须 34：TopAppBarButton 与 SegmentedControl 的 lint 声明为 API 34。
2. CouiPageColors 只有 background/card/title/summary/disabled/accent/divider，
   没有 danger/secondary/isDark/accentSurface，这些在 CouiKit.kt 里用扩展属性补齐。
3. @Composable get() 扩展属性在非组合 getter 里不可用，CouiType 的角色改成
   @Composable fun xxx(): TextStyle。
4. 上一版顶部栏是自己画的，TopAppBarButton 在顶栏作用域外拿不到
   LocalCouiToolbarBackdrop，会失去模糊采样。现在统一用 Scaffold + TopAppBar。
5. 「列表密度」选项删除：COUI 行高固定 48dp，密度不再可控；
   「界面比例」的说明改为"COUI 组件行高固定 48dp，这里整体缩放界面与字号"。
